02Description of the Service

Quello provides tools for:

  • creating, editing, and deleting QOTD posts and creating related threads;
  • managing counters and viewing history, statistics, normal QOTD logs, and detailed interaction audit logs;
  • configuring channels and roles, and enabling maintenance or QOTD lock modes;
  • accepting and reviewing member-submitted question suggestions;
  • showing personal and server participation statistics, plus public global leaderboards;
  • a website with documentation and a sign-in dashboard for managing server settings and QOTDs; and other related features.

Quello also offers server-specific QOTD categories, achievements, a public global leaderboard, opt-in public profiles, an opt-in Server Discovery directory and the signed-in Feedback Center.

04Server Administration

Server owners and administrators are responsible for deciding whether to install Quello, which permissions to grant it, and how its administrative features are configured.

For Discord slash commands, access is checked separately for each server. The Bot Owner (identified by BOT_OWNER_ID) retains global owner access, while the Server Owner has owner access only in their own server. A member with Discord’s Administrator permission may use /setup, /config, /maintenance, /lock, /schedule_qotds and /schedule_config. Administrator permission alone does not grant QOTD Manager access to /qotd, /edit, /delete, /suggestions or /random_qotd; those commands require the server’s configured allowed role or Bot Owner/Server Owner access. Discord Developer Portal team roles (Admin, Developer and Read Only) are separate from Discord server permissions and do not grant Quello access in this release.

06Website and Dashboard

The Quello website offers a dashboard where you sign in with Discord OAuth2 using the identify and guilds scopes. Quello reads your basic profile and server permission flags to identify servers where you are the owner or have Administrator permission. What you can do depends on your role in the server:

  • In the website Dashboard, the server owner, a Discord Administrator, or the Bot Owner can complete initial setup, view and change server settings, manage Scheduled QOTD, use maintenance and lock controls, publish and edit QOTDs, review suggestions, and access the server’s activity and audit logs.
  • Members with the server’s configured allowed role can view settings, publish and edit QOTDs, review suggestions, and view leaderboards and statistics. This role does not grant permission to change server-wide settings.

You are responsible for actions taken through your signed-in session, and you must not share, attempt to forge or misuse session access, or attempt to access servers or data you are not authorized for. 13Scheduled QOTD and AI-generated content

If enabled by a server owner, Scheduled QOTD generates and publishes questions at the configured interval (every 1, 6, 12 or 24 hours), using the server’s configured bot language and recent QOTD context. An authorized QOTD manager may also run /random_qotd to generate and publish a question immediately. Both features use Groq, an independent third-party service. The server owner is responsible for deciding whether these features are appropriate and for avoiding confidential or sensitive content in recent QOTDs sent as prompt context.

AI-generated questions may occasionally be unsuitable, inaccurate, repetitive, or unexpected. Quello does not guarantee that generated questions will be error-free or appropriate for every community. Server administrators can disable Scheduled QOTD at any time; /random_qotd only runs when an authorized member invokes it.

For temporary generation or publication errors, Quello retries every five minutes for up to one hour. Non-retryable API errors, including authentication, permission, or invalid-model errors, are not retried for the same slot; the slot is skipped and the server owner is notified. After repeated temporary failures, Quello also attempts to notify the server owner in English.

15Developer Team and Admin Panel access

Quello reads Discord Developer Team metadata to verify who may use the Admin Panel. Access is granted to the Bot Owner, the verified Developer Team Owner, and accepted Developer Team members with the Admin or Developer role. Read-only members, pending invitations and everyone else have no Admin Panel access.

All four roles can use System Overview, Announcements, Owner Actions (including Technical Work Mode and Dashboard session management) and Developer Actions. Access is checked on the server for every request. You are responsible for actions you take in the Admin Panel, which may only be used to operate and support Quello.

16Global Announcements

Authorized Admin Panel users (the Bot Owner, the verified Team Owner, and Team Admins and Developers) may create global announcements through the Admin Panel. An announcement is published only to Discord servers that have configured an optional Announcement Channel. Authorized Admin Panel users can edit or delete a managed announcement; edits and deletions are applied to the copies Quello successfully published.

17Daily QOTD publication limit

Each Discord server may publish a maximum of one QOTD per UTC calendar day, shared by all members of that server. If any member publishes a QOTD, no other member of that server can publish another until the limit resets at 00:00 UTC. The limit is independent for each server, applies to all members and authorized users without an owner bypass, and does not depend on local time zones. Manual, scheduled, random and approved-suggestion publications all use the same server-wide daily allowance.

18Optional community features

QOTD categories are scoped to individual Discord servers. Server members with the configured QOTD manager role, the Bot Owner or the Server Owner may manage categories through the available bot controls. Categories can be attached to manual, random and scheduled QOTDs.

Public profiles are private by default and become visible only when the account owner opts in. The profile owner controls whether answer counts, created-question counts and achievement information are shown. Discord profile banners are displayed only when Discord makes a banner available.

Server Discovery is an optional directory. A server owner or Discord administrator controls whether a listing is public and is responsible for the description and invite link they submit. Public listings may show the server name, icon, member count, category, description and invite URL.

The Feedback Center lets signed-in users submit ideas, bug reports and other feedback and exchange replies with the Quello team. The team may update a feedback item’s status. Submitting feedback does not guarantee that a suggestion will be accepted or implemented, or that a response will arrive within a particular time.
