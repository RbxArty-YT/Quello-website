# Fonts

## TwemojiCountryFlags.woff2

Country flag emoji font used so flags render as images on systems without
native flag emoji (e.g. Windows shows "RU", "DE" letters instead).

- Source: [country-flag-emoji-polyfill](https://github.com/talkjs/country-flag-emoji-polyfill) v0.1.10 by TalkJS,
  file `dist/TwemojiCountryFlags.woff2`, redistributed unmodified.
- The font is a subset (country flags only) of [Twemoji Mozilla](https://github.com/mozilla/twemoji-colr), made by TalkJS.
- Flag artwork: [Twemoji](https://github.com/twitter/twemoji) — Copyright Twitter, Inc. and other contributors,
